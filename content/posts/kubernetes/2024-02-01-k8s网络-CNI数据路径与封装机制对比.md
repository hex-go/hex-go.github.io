> 本文是系列文章的「横向对比」——把各方案的数据路径和封装机制放一张图里看，聚焦「包是怎么走的」，不做选型推荐。Underlay（Host-GW / Calico BGP）和 Cilium 待补充。

## 1. 统一的起点

所有容器网络方案的起点完全一致：

1. 每个容器的网络栈，都是基于**网卡 IP** 生成两条路由——**直连路由**（本机子网）+ **默认路由**（网关）。
2. 容器与宿主机之间，都靠 **veth-pair** 连接（一端是容器 `eth0`，一端是宿主机侧 veth）。

方案的分叉，从「veth 对端插到哪」开始。

## 2. 第一层区别：有没有网桥（决定同节点通信）

| | 有网桥（Docker / Flannel） | 无网桥（Calico） |
|--|--------------------------|-----------------|
| veth 对端 | 插进 `docker0` / `cni0` 网桥 | 直接挂宿主机（`cali*` 接口） |
| 同节点转发 | 二层 **CAM 表**（MAC → 端口） | 三层 **/32 路由**（IP → cali*） |
| 转发模型 | 桥接 | 路由 |

- **有网桥**：同节点 Pod 通信走网桥 CAM 二层转发，跨节点时网桥当三层接口上交宿主机。
- **无网桥**：同节点 Pod 通信走宿主机 `/32` 路由，出接口直接是目标 Pod 的 `cali*`——用「per-pod 路由 + proxy ARP」取代网桥。

## 3. 第二层区别：跨节点怎么封装（Overlay）

### 3.1 Flannel UDP（用户态，L3 over L4，仅演示）

```
Pod → cni0 → 路由 → flannel0(TUN) → flanneld(用户态) → UDP 封装 → 对端
```

- 靠 TUN 特性，IP 包从内核「冒」到用户态 `flanneld` 进程。
- `flanneld` 查 etcd 得「目标 Pod IP → 目标宿主机 IP」，封 **UDP（协议号 17，端口 8285）**。
- 三次用户态↔内核态切换，性能最差，生产禁用。

### 3.2 Flannel VXLAN（内核态，L2 over L4，生产通用）

```
Pod → cni0 → 路由(via 对端VTEP-IP dev flannel.1) → ARP(VTEP-IP→VTEP-MAC) → FDB(VTEP-MAC→宿主机IP) → VXLAN 封装 → 对端
```

- 内核态 VTEP（`flannel.1`），**内核 socket 绑 UDP 8472**，零用户态切换。
- **ARP + FDB 两级查表**：ARP 拿内层 MAC（VTEP-MAC），FDB 拿外层 IP（宿主机 IP）。这两张表是 `flanneld` 从 etcd/K8S **预置**的，不是运行时广播学习。

### 3.3 Calico VXLAN（内核态，L2 over L4）

与 Flannel VXLAN **唯一区别是少了 cni0 网桥这一跳**——veth 直接走宿主机 /32 路由再进 VTEP。封装逻辑、ARP/FDB 完全一样。

### 3.4 Calico IPIP（内核态，L3 over L3）

```
Pod → cali* → 路由(via 直接是对端宿主机IP dev tunl0) → IPIP 封装 → 对端
```

- 路由 `via` **直接就是宿主机 IP**，不需要 ARP + FDB 两级查表。
- 外层用 **IP 协议号 4** 分发（不是 UDP 端口），**没有 socket**。
- 只加一层外层 IP 头，开销 20B；代价是失去二层能力（无广播/组播、不支持 IPv6）。

## 4. 关键洞察：每层都有一对「地址 + 分发」

| 层 | 转发/路由依据 | 分发/分拣依据 |
|----|--------------|--------------|
| L2 | MAC（发给谁） | EtherType（0x0800=IPv4、0x0806=ARP） |
| L3 | IP + 路由 | 协议号（4=IPIP、6=TCP、17=UDP） |
| L4 | —（端到端） | 端口（→ socket） |

分发永远是**两级**：第一级把包带到子系统，第二级精确定位——

| 协议 | 第一级（进子系统） | 第二级（到具体对象） |
|------|-----------------|--------------------|
| TCP/UDP | 协议号 6/17 | 端口 → socket |
| VXLAN | UDP 端口 8472 | VNI → 具体 vxlan 设备 |
| IPIP | 协议号 4 | 外层 IP → 具体 ipip 设备（tunl0 兜底） |

## 5. 开销对比

| 方案 | 封装内容 | 开销 | 二层能力 |
|------|---------|------|---------|
| Flannel UDP | 外层 IP + UDP | 28B | 无 |
| Flannel/Calico VXLAN | 内层MAC + VXLAN + UDP + 外层 IP | 50B | 有 |
| Calico IPIP | 外层 IP（protocol=4） | 20B | 无 |
