## 1.简介

RPC是分布式系统的基础，可以像调用本地一样发起远程调用。是解决分布式系统通信问题的一大利器。

> 分布式系统包括：消息队列、分布式缓存、分布式数据库、配置中心等

RPC对网络通信的整个过程（查找对端节点、建立网络连接、编解码数据、网络连接管理）做了完整的包装，在搭建分布式系统时，简化网络通信逻辑的开发、确保网络通信的安全可靠。



RPC**基础**（基本原理与网络通信）：序列化、编解码、网络传输等。

RPC**进阶**（治理功能、集群管理）：连接管理、健康检测、负载均衡、优雅启停机、异常重试、业务分组、熔断限流等。

RPC**高级**：性能优化与问题定位解决。



## 2.概念

RPC（Remote Procedure Call）即远程过程调用。指屏蔽网络编程细节，跨机器而非本机实现调用远程方法与调用本地（同一项目中的方法）一样的体验。

- 屏蔽远程调用与本地调用的区别
- 隐藏底层网络通信的复杂新

RPC调用流程：

```
客户端                                    服务端
  |                                         |
  |--(1) 调用本地Stub函数------------------->|
  |       (函数名、参数)                      |
  |                                         |
  |--(2) 序列化参数------------------------->|
  |       (Marshal)                         |
  |                                         |
  |--(3) 网络传输(HTTP/TCP)----------------->|
  |                                         |
  |                                    (4) 反序列化
  |                                    (5) 调用实际函数
  |                                    (6) 执行业务逻辑
  |                                         |
  |<--(7) 返回结果(序列化)-------------------|
  |                                         |
  |--(8) 反序列化结果                         |
  |                                         |
  |--(9) 返回给调用方                         |
```

关键步骤：
1. 客户端调用Stub（桩）函数，像调用本地函数一样
2. Stub将函数名、参数序列化（编码）
3. 通过网络发送到服务端
4. 服务端反序列化，获取函数名和参数
5. 调用实际的服务端函数执行
6. 将返回值序列化后发送回客户端
7. 客户端反序列化得到结果
